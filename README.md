# Kitsune Redline

Browser GT3 racing game (Three.js, procedural graphics) with a rival AI that learns from you.

Play: https://YOUR-USERNAME.github.io/YOUR-REPO/

Controls: W/A/S/D or arrows to drive, Space for nitro, P or Esc to pause. Touch controls on mobile.

Built for HTML5 game portals; all game files are in the repository root (no subfolders).
